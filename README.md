# CampusManager – Java Console Application

CampusManager is a console-based Java application for managing university
modules and calculating study-related statistics.

## Project Context

This project was developed in a two-person team as part of the Practical
Informatics 1 module at TH Köln during the first semester.

## Features

- Add and display university modules
- Store module names, ECTS credits, and grades
- Validate user input
- Calculate total ECTS
- Count passed modules
- Calculate the weighted average grade
- Delete modules
- Sort modules by grade
- Generate a semester overview
- Display a menu-based console interface
