# Praktikum 2 – Java Console Applications

This repository contains Java console exercises developed as part of
Praktikum 2 in Practical Informatics 1 at TH Köln.

## Project Context

The exercises were completed during the first semester in a two-person team.

## Exercises

### Menu-Based CampusManager

- Add and display module data
- Change a module grade
- Check a bonus rule
- Display an ECTS progress bar
- Generate a time schedule
- Use menus, loops, and switch-case
- Validate user input

### Batch Module Analysis

- Enter several module records
- Count passed modules
- Calculate passed and total ECTS
- Calculate the pass rate
- Check whether at least 30 ECTS were passed

### Weekly Schedule Generator

- Generate a schedule for several weeks
- Use nested loops and conditions
- Apply week-based scheduling rules
- Display activities from Monday to Friday
